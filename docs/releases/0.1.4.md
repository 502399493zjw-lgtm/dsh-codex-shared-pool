# 0.1.4：新版 DSH 兼容，更清楚的团队共享与额度管理

`dsh-codex-shared-pool@0.1.4` 已在 npm 发布。本次补齐 GitHub 上新说明：继续提供本地多账号池和自托管团队共享，并将兼容基线升级到官方 DSH **0.1.2-rc.1 / Cordis 4.0.2**。

## 这个版本更新了什么

- **适配新版 DSH**：修复设置和浏览器服务接口变化导致的加载失败，迁移模型请求准备和图片访问流程；增加 Windows、Linux 的官方 DSH 安装及启动验证。
- **更清楚的账号与额度**：突出账号名称，统一本机与共享账号的订阅、额度和刷新入口；本地额度显示重置时间。
- **更明确的共享保护**：分别展示本周共享用量 / 上限、账号剩余额度与 API 等价金额估算；输入有误或保存失败时就地提示并保留输入。
- **更顺畅的日常操作**：成员页可直接创建邀请；侧边栏额度刷新失败时保留上次成功数据，标注过期状态和最后更新时间。

## 如果你还停留在 0.1.2

0.1.3 已加入可供多名成员使用的邀请码、与建队分开的所有者恢复入口，以及共享预算接纳判断的修复。配合现有的浏览器共享授权、团队切换和 Docker 自托管能力，贡献者可以决定共享哪些账号及其每周预算；加入团队的成员无需登录贡献者的 OpenAI 账号。

## 安装与升级

```sh
npx @deepseek-ai/dsh@0.1.2-rc.1 plugin --profile web add dsh-codex-shared-pool@0.1.4
npx @deepseek-ai/dsh@0.1.2-rc.1 web
```

升级前备份 DSH 数据并退出旧进程。启动后在 **设置 → Codex 订阅池** 管理账号，在会话中手动选择 Codex 模型。仍使用 DSH 0.1.0-rc.8 的实例对应插件 0.1.3。自托管团队需要同步更新匹配的 Host/Broker 并运行数据库迁移，详见 [升级说明](https://github.com/502399493zjw-lgtm/dsh-codex-shared-pool#额度订阅与升级排障)。

## 实测范围

公开 npm 包已在独立 DSH 实例中完成：浏览器共享授权 → 新成员真实请求 → 每周共享预算达限拒绝 → 解除限制后请求恢复。成员实例未配置本地 Codex 账号。

测试运行在同一电脑的独立进程、数据目录和浏览器配置中；尚未验证第二台物理设备、跨网络连接或上游订阅额度真正耗尽。当前版本也尚未移除 `device_code`。
