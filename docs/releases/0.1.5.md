# 0.1.5：默认连接云端团队，连接失败可定位与恢复

`dsh-codex-shared-pool@0.1.5` 补齐全新安装的云端团队入口，并继续兼容官方 DSH **0.1.2-rc.1 / Cordis 4.0.2**。

同时调整额度展示：重置时间仅显示在 Codex 额度窗口下，并使用更轻的文字样式，减少重复提示。

## 安装后怎么用

```sh
npx @deepseek-ai/dsh@0.1.2-rc.1 plugin --profile web add dsh-codex-shared-pool@0.1.5
npx @deepseek-ai/dsh@0.1.2-rc.1 web
```

全新安装无需手动填写服务地址。打开 **设置 → Codex 订阅池 → 团队**，点击 **创建团队**，或粘贴云端团队的邀请码并确认加入。创建后私密保存所有者恢复码；成员使用邀请码，无需登录贡献者的 OpenAI 账号。

默认连接模式下，尚未加入团队时，模型请求继续使用本机 Codex 账号池。创建或加入成功后，下一次请求使用 Team；断开本机连接后，下一次请求恢复使用本机账号池。已选择 Team 的请求遇到权限、限额或网络错误时保留该错误，不会自动转用本机账号。

## 从 0.1.4 升级

升级前备份 DSH 数据并退出旧进程，再安装 `0.1.5`、启动原 Web profile。仍使用 DSH `0.1.0-rc.8` 的实例对应插件 `0.1.3`。

- **原本能正常使用云端团队**：直接升级，原团队、成员身份和共享账号保留，无需创建新团队或重新加入。
- **原来没有配置团队服务**：升级后默认出现云端创建、加入入口；使用原云端团队的邀请码，或用所有者恢复码恢复管理身份。
- **原来显式指向 `localhost`、`127.0.0.1` 或 `::1`**：这些地址指向运行 DSH 的电脑，升级会保留配置。若要使用云端，请由维护者恢复正确的服务地址及对应的云端凭据；创建新团队或再次加入不能修复错误地址、断网或服务停机。
- **使用自托管服务或显式禁用团队连接**：已有配置继续生效，升级不会自动切换服务或重新启用连接。

本机测试服务里的团队、邀请码和成员密钥只属于那台服务，不能直接迁移成云端身份。若决定在云端新建独立团队，成员需使用新邀请码加入，要贡献的账号也需在新团队授权。默认云端入口使用独立凭据名称，不会把旧测试服务的密钥或未完成的加入记录自动发送到云端。

具体配置和恢复步骤见 [团队连接与恢复](https://github.com/502399493zjw-lgtm/dsh-codex-shared-pool/blob/main/docs/team-connection.md)。

## 服务不可用时

团队页面显示当前服务地址，并按本机服务或远端服务给出检查步骤。连接失败保留本机成员凭据；恢复服务或网络后点击 **重试**。只有“团队访问已失效”才进入凭据失效的恢复流程，不必因为暂时断网清除连接。
